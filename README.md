# Tunnel vision

Crop the client to secretly multitask.

Hold down the ALT key and use the mouse scroll wheel to change the size of the cropped area.

![animation](https://github.com/user-attachments/assets/d5c54848-907e-4676-9b58-326496774953)

## Settings

- **Circle radius**: size of the visible circle. ALT + scroll also changes and saves it.
- **ALT + scroll step**: how much each scroll tick changes the radius.
- **Hide when cursor away**: hide the client completely while the mouse is outside the client's area. Moving back over it shows the circle under the cursor.
- **Full window hotkey**: toggle between the circle and the full window (Ctrl+Shift+F by default).
- **Always show title bar** / **Keep sidebar visible**: keep those parts of the window visible alongside the circle.

The client can be resized by dragging its edges wherever the circle (or the full window) covers them.
